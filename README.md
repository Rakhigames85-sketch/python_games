# 🐍 Snake Game in Python

A classic Snake Game built using Python and Pygame. My first project while learning game development.

### 🎮 How to Play
- **Arrow Keys** - Move the Snake Up, Down, Left, Right
- **C** - Play Again after Game Over  
- **Q** - Quit the Game

### 🚀 How to Run
1. Install Python 3
2. Install Pygame: `pip install pygame`
3. Run the game: `python snake.py`

### 💡 What I Learned
- Python basics and loops
- Game development with Pygame
- Collision detection and event handling

### 🛠️ Tech Stack
Python, Pygame Library
